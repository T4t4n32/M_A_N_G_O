## 🎯 VISIÓN GENERAL

### **Objetivo del Proyecto**
Crear una landing page institucional profesional para M.A.N.G.O, un sistema de monitoreo ambiental para protección de manglares y ecosistemas marítimos, con acceso restringido a instituciones autorizadas.

### **Público Objetivo**
- **Visitantes generales**: Pueden ver información pública sobre el proyecto
- **Instituciones autorizadas**: ONGs, universidades, colegios, ministerios de ambiente, sectores enfocados al ecosistema y cuidado marítimo
- **Técnicos y desarrolladores**: Acceso a documentación técnica

### **Tecnología Stack**
- **Frontend**: HTML5, CSS3 (SASS), JavaScript ES6+
- **Gráficos**: Chart.js para dashboard
- **Backend**: API REST (ya funcional en http://localhost:8080)
- **Base de datos**: PostgreSQL + Redis (time-series)

## 📝 CONTENIDO POR SECCIÓN

### **Contenido para "¿Qué es M.A.N.G.O?"**

```
M.A.N.G.O (Monitoreo Autónomo de Niveles y Gestión Oceánica) es un sistema 
institucional de monitoreo ambiental diseñado para recopilar, almacenar y 
analizar datos del mundo real provenientes de sensores físicos desplegados 
en entornos acuáticos y naturales.

La plataforma está restringida exclusivamente a instituciones autorizadas 
como ONGs, universidades, fundaciones, ministerios ambientales y empresas 
con enfoque en sostenibilidad.

Todos los datos son reales, continuos y no simulados, provenientes de 
sensores físicos operativos en campo.
```

### **Contenido para "Componentes Integrados"**

```
Sensores Físicos:
- pH Sensor + Module: Mide acidez/alkalinidad del agua (rango 0-14 pH)
- PT100 (3-wire) + MAX31865: Mide temperatura con alta precisión (-50°C a +150°C)
- Turbidity Sensor (TSW-20M): Mide turbidez del agua para análisis ambiental (0-1000 NTU)

Hardware de Adquisición:
- Microcontrolador para procesamiento de datos
- Sistema de comunicación segura
- Alimentación y protección ambiental

Plataforma de Monitoreo:
- Backend API RESTful
- Base de datos time-series
- Sistema de cache Redis
- Dashboard de visualización científica
```

### **Contenido para "Metodología de Implementación"**

```
1. Despliegue de Sensores
   - Instalación física en ubicaciones estratégicas
   - Calibración inicial de cada sensor
   - Configuración de comunicación

2. Comunicación de Datos
   - Sensores → Microcontrolador → API Backend
   - Validación y verificación de datos
   - Almacenamiento en base de datos time-series

3. Procesamiento y Almacenamiento
   - Validación de integridad de datos
   - Almacenamiento histórico append-only
   - Cache de datos recientes en Redis

4. Mapeo Geográfico
   - Ubicación GPS de cada estación
   - Visualización en mapa interactivo
   - Contexto ambiental de cada punto

5. Visualización Científica
   - Dashboard con gráficos en tiempo real
   - Análisis de tendencias históricas
   - Sistema de alertas y notificaciones
```

### **Endpoints del Backend (ya funcionales)**

```javascript
// Base URL: http://localhost:8080 (usar rutas relativas /api/v1/...)
const API_BASE = '/api/v1'; // No hardcodear localhost:8000

// 1. Verificación de salud del sistema
GET `${API_BASE}/health`
Response: { status: "ok", db: "ok" }

// 2. Obtener métricas disponibles
GET `${API_BASE}/metrics`
Response: { metrics: ["ph", "temp", "turbidity"] }

// 3. Obtener últimos valores por tipo
GET `${API_BASE}/latest/by_type`
Response: {
  latest: {
    ph: { value: 7.45, unit: "pH", ts: "2026-02-26T10:30:00Z" },
    temp: { value: 23.8, unit: "°C", ts: "2026-02-26T10:30:00Z" },
    turbidity: { value: 12.3, unit: "NTU", ts: "2026-02-26T10:30:00Z" }
  }
}

// 4. Obtener serie temporal histórica
GET `${API_BASE}/range?type=temp&minutes=60`
Response: {
  series: [
    { ts: "2026-02-26T09:30:00Z", value: 23.5, unit: "°C" },
    { ts: "2026-02-26T09:35:00Z", value: 23.6, unit: "°C" }
  ],
  count: 12
}
```

// 1. Tratar value = -1 como "sin datos"

  status = "Sin datos";

if (response.count === 0) {

metrics.forEach(metric => {
