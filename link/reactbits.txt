Usemos esto que sigue para las fotos de "Temporadas que Construyeron el Camino" y la de "Hitos y Expasion", y ademas, agrega la opcion de hacer clic y que haga expanda la imagen, asi que integremos eso con lo siguiente:
Circular Gallery:
npx shadcn@latest add @react-bits/CircularGallery-TS-CSS
import CircularGallery from './CircularGallery'

<div style={{ height: '600px', position: 'relative' }}>
  <CircularGallery bend={3} textColor="#ffffff" borderRadius={0.05} scrollEase={0.02}
  bend={0}
  borderRadius={0.13}
  scrollSpeed={3.1}
  scrollEase={0.07}
/>
</div>

Para cuando la pagina arroje "404", colocar este texto:
Fuzzy Text:
npx shadcn@latest add @react-bits/FuzzyText-TS-CSS
import FuzzyText from './FuzzyText';
  
<FuzzyText 
  baseIntensity={0.2}
  hoverIntensity={0.5}
  enableHover
>
  404
</FuzzyText>
