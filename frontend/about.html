🌿 Sobre M.A.N.G.O

Monitoreo Autónomo de Niveles y Gestión Oceánica

🎯 Misión y Visión

Misión

Desarrollar y desplegar un sistema de monitoreo ambiental autónomo para la protección y conservación de ecosistemas de manglares colombianos, proporcionando datos precisos y en tiempo real para la toma de decisiones informadas en la gestión ambiental.

Visión

Ser el sistema de referencia para el monitoreo de ecosistemas costeros en Colombia, contribuyendo a la preservación de los manglares como ecosistemas vitales para la biodiversidad y las comunidades costeras, mediante tecnología accesible y sostenible.

🎯 Objetivos del Proyecto

Monitoreo Continuo

Implementar un sistema de monitoreo continuo y autónomo de parámetros ambientales críticos en ecosistemas de manglares.

Base de Datos

Crear una base de datos histórica de calidad del agua y condiciones ambientales para análisis a largo plazo.

Comunidad

Capacitar y empoderar a comunidades locales en el uso de tecnología para la conservación ambiental.

Código Abierto

Mantener el proyecto 100% open-source para fomentar la colaboración y replicabilidad en otros ecosistemas.

🛠️ Tecnología Utilizada

Hardware

  • NVIDIA Jetson TK1: Procesamiento principal y control
  • ESP32 + LoRa: Comunicación inalámbrica de largo alcance
  • Sensor de pH: Medición de acidez/alkalinidad del agua
  • Sensor de Temperatura: Monitoreo térmico continuo
  • Sensor de Turbidez: Medición de partículas suspendidas
  • Propulsores APISQUEEN: Movimiento autónomo del dispositivo
  • Kinect V1: Mapeo 3D y SLAM
  • Batería LiPo 3S: Alimentación de 5000mAh para autonomía

Software

  • Python 3.11: Lenguaje principal del backend
  • Flask: Framework web para API REST
  • PostgreSQL + PostGIS: Base de datos espacial
  • Chart.js: Visualización de datos en tiempo real
  • HTML5/CSS3/JavaScript: Frontend moderno y responsivo
  • Docker: Contenerización para despliegue
  • Git/GitHub: Control de versiones y colaboración

✨ Características Principales

Tiempo Real

Datos actualizados cada 30 segundos directamente desde los sensores

Sin Simulaciones

100% datos reales, nunca simulados. Si no hay datos, se indica explícitamente

Modo Offline

Funciona incluso sin conexión, mostrando datos históricos reales

Alertas Inteligentes

Notificaciones automáticas para valores fuera de rango o fallos del sistema

Gráficos Interactivos

Visualización avanzada con Chart.js para análisis de tendencias

Seguridad

Autenticación segura, HTTPS y encriptación de extremo a extremo
