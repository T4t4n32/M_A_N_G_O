🌿 Sobre M.A.N.G.O

Monitoreo Autónomo de Niveles y Gestión Oceánica

🎯 Misión y Visión

Misión

Desarrollar y desplegar un sistema de monitoreo ambiental autónomo para la protección y conservación de ecosistemas de manglares colombianos, proporcionando datos precisos y en tiempo real para la toma de decisiones informadas en la gestión ambiental.

Visión

Ser el sistema de referencia para el monitoreo de ecosistemas costeros en Colombia, contribuyendo a la preservación de los manglares como ecosistemas vitales para la biodiversidad y las comunidades costeras, mediante tecnología accesible y sostenible.

👤 El Creador

Sebastián Sánchez Chacón

Creador y Desarrollador Principal

Estudiante de Electrónica con pasión por la conservación ambiental y la tecnología. Desarrollador del proyecto M.A.N.G.O como iniciativa personal para proteger los ecosistemas de manglares colombianos mediante monitoreo tecnológico accesible.

Este proyecto representa un esfuerzo educativo y científico para apoyar el monitoreo ambiental en los manglares colombianos, originalmente iniciado con el grupo "CALIBOTS" y continuado de forma independiente.

📌 Objetivos del Proyecto

🔬

Monitoreo en Tiempo Real

Implementar sensores autónomos para medir pH, temperatura y turbidez en ecosistemas de manglar.

📡

Transmisión de Datos

Utilizar tecnología LoRa para transmisión de datos en zonas remotas con bajo consumo energético.

📊

Visualización Accesible

Crear un dashboard intuitivo para visualización de datos y generación de reportes para comunidades y autoridades.

🌱

Conservación Sostenible

Contribuir a la preservación de los manglares mediante información precisa para la toma de decisiones ambientales.

⚙️ Tecnología Utilizada

Hardware

  • NVIDIA Jetson TK1
  • Módulo LoRa (SX1262)
  • Sensores: pH, Temperatura, Turbidez
  • Raspberry Pi 4 (pruebas terrestres)
  • Intel Neural Compute Stick 2 (IA)

Software

  • Backend: Python + Flask
  • Frontend: HTML5, CSS3, JavaScript
  • Base de Datos: PostgreSQL + PostGIS
  • Comunicación: Protocolo LoRaWAN
  • Docker para despliegue
