M.A.N.G.O.

Monitoreo Autónomo de Niveles y Gestión Oceánica

Proyecto tecnológico orientado al monitoreo ambiental en cuerpos de agua, integrando sensores, automatización e Internet de las Cosas (IoT) para apoyar la sostenibilidad y la toma de decisiones.

Planteamiento del Problema

La falta de monitoreo continuo y en tiempo real de variables físico-químicas en cuerpos de agua dificulta la detección temprana de cambios ambientales que afectan ecosistemas acuáticos y actividades productivas como la acuicultura.

Muchos procesos de medición aún se realizan de forma manual, lo que genera retrasos, errores humanos y pérdida de información crítica.

Objetivos

Objetivo General

Diseñar e implementar un sistema de monitoreo autónomo capaz de medir, registrar y visualizar variables ambientales en cuerpos de agua.

Objetivos Específicos

  • Implementar sensores de temperatura, pH y turbidez.
  • Automatizar la recolección y transmisión de datos.
  • Desarrollar una plataforma web para visualización.
  • Garantizar escalabilidad y bajo consumo energético.

Justificación

M.A.N.G.O. contribuye a la protección ambiental mediante el uso de tecnología aplicada, alineándose con los Objetivos de Desarrollo Sostenible (ODS), especialmente el ODS 14: Vida submarina.

El sistema permite mejorar la toma de decisiones, reducir costos operativos y fomentar prácticas sostenibles en entornos acuáticos.

Marco Teórico

El proyecto se fundamenta en conceptos de Internet de las Cosas (IoT), donde dispositivos interconectados recopilan y transmiten datos en tiempo real.

Se aplican principios de sensórica ambiental, redes de comunicación, sistemas embebidos y plataformas web para el análisis y visualización de datos.

Alcance del Proyecto

  • Monitoreo básico de variables ambientales.
  • Visualización de datos en una interfaz web.
  • Uso educativo y demostrativo (prototipo funcional).

Tecnologías Utilizadas

  • Sensores ambientales (temperatura, pH, turbidez).
  • Microcontroladores y sistemas embebidos.
  • Servidor VPS con Nginx.
  • Desarrollo web (HTML, CSS, JavaScript).
