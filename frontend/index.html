¿Qué es M.A.N.G.O.?

M.A.N.G.O. es un sistema tecnológico diseñado para el monitoreo ambiental de ecosistemas marinos y costeros. Integra sensores físicos reales, procesamiento local y visualización de datos en tiempo real mediante una plataforma web.

Procesamiento Local

Los datos se procesan localmente sin simulaciones, garantizando información real y verificable.

Comunicación IoT

Integración de sensores mediante protocolos de comunicación eficientes y escalables.

Visualización Clara

Dashboard web para análisis de variables ambientales en tiempo real.

Tecnologías Implementadas

  • Jetson (procesamiento local)
  • Sensores ambientales reales
  • Python + Flask (backend)
  • HTML, CSS, JavaScript y Bootstrap
  • Arquitectura modular y escalable

Impacto Ambiental

M.A.N.G.O. busca contribuir a la protección de ecosistemas como manglares, arrecifes y zonas costeras, proporcionando datos que faciliten la toma de decisiones basadas en evidencia científica.

Sobre el Creador

Mi nombre es Sebastián, creador de M.A.N.G.O. Este proyecto nace de la combinación entre tecnología, ciencia y la necesidad de generar soluciones reales para el monitoreo ambiental. M.A.N.G.O. no es una idea conceptual: es un sistema funcional, escalable y en constante evolución.
