¿Qué es M.A.N.G.O?

M.A.N.G.O es un sistema de monitoreo ambiental diseñado para recopilar, visualizar y analizar datos reales provenientes de sensores desplegados en ecosistemas oceánicos y costeros.

El proyecto prioriza la transparencia: si no existen datos disponibles, el sistema lo indicará explícitamente.
