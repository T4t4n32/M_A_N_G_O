¿Qué es M.A.N.G.O.?

M.A.N.G.O. es una plataforma de monitoreo ambiental oceánico que integra sensores físicos, procesamiento local y visualización web para recolectar datos reales sobre el estado del entorno marino.

Datos reales

Sin simulaciones. Información obtenida directamente desde sensores físicos.

Arquitectura escalable

Diseñado para crecer desde un prototipo hasta una red de estaciones.

Acceso controlado

Plataforma segura con visualización diferenciada por roles.

Sobre el creador

Soy Sebastián, creador de M.A.N.G.O. Este proyecto nace de la necesidad de unir tecnología, ingeniería y conciencia ambiental en un sistema funcional. M.A.N.G.O. no es solo una idea: es una plataforma pensada para operar, medir y evolucionar.

Tecnologías implementadas

ESP32 + Sensores
Jetson (Edge Computing)
Flask + API
Dashboard Web

Impacto ambiental

M.A.N.G.O. permite tomar decisiones basadas en datos, mejorar la gestión ambiental y apoyar procesos educativos, científicos e institucionales.
